# Proyecto de POO Bancaria

## Descripción
Este proyecto consiste en un simulador bancario desarrollado en Java, aplicando los conceptos de programación orientada a objetos, encapsulamiento y herencia.

## Clases del proyecto
- **CuentaBancaria.java:** administra el saldo, los depósitos y los retiros.
- **CuentaAhorro.java:** permite realizar retiros con comisión por exceso y calcular intereses mensuales.
- **CuentaCorriente.java:** permite utilizar un sobregiro y realizar pagos para reducir la deuda.
- **Main.java:** ejecuta las pruebas de las cuentas bancarias.

## Requisitos
- Java JDK.
- Apache NetBeans.

## Instrucciones de ejecución
1. Abrir el proyecto en Apache NetBeans.
2. Abrir la clase `Main.java`.
3. Ejecutar el programa.
4. Revisar los resultados en la ventana de salida.
